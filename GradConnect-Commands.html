GradConnect Commands

The basic commands for running and resetting the app while you test it. Use it alongside the Testing Guide.

Before you start: start Docker Desktop, then open a terminal inside the project folder (the one with docker-compose.yml). Click Copy on a command, paste it into the terminal, and press Enter.

Start and stop

docker compose up -d
Start the app. Then open http://localhost:8000.
docker compose up -d --build
Start with the latest code. Use this after pulling new changes from GitHub. Takes a few minutes.
docker compose down
Stop the app. Your data is kept for next time.
docker compose ps
Check it is running. app, db, mail and queue should all say running.

When something goes wrong

docker compose logs -f app
See errors as they happen. Open the broken page again and the error appears here. Press Ctrl + C to stop watching.
docker compose exec app php artisan optimize:clear
Clear saved copies. Fixes a change or setting that doesn't seem to show up. Safe; nothing is lost.
docker compose restart app
Restart the website. Try this if pages stop loading.

Database

docker compose exec app php artisan migrate
Update the database to match the code. Applies any new database changes and keeps all existing data. The app also does this by itself every time it starts.
docker compose exec app php artisan db:seed
Fill an empty database with demo data. Only works on an empty database. If the demo accounts already exist it stops with an error, because their emails are taken; use the reset command below instead.
docker compose exec app php artisan migrate:fresh --seed
Deletes dataStart over with clean demo data. Erases everything, including accounts you registered, then recreates the demo accounts, colleges, postings and surveys. Use it before a demo, or when the data gets messy.
